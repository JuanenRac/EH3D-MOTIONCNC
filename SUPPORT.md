# Support

* **Questions and ideas:** open an issue with the form that fits.
* **A theme or a text that looks wrong:** say which theme and language, and attach the theme file if it is your own.
* **Machine control:** there is none yet. Ideas about how an operator should work with drilling, routing and 2D and 3D jobs in one program are welcome, especially if you use a machine-control program today and can say what you miss in it.

This is a one-person project and the program is at its first steps: answers can take a few days.
